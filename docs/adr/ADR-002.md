# ADR-002 — Kafka introduction point

- Status: Accepted (P5), deferred in the monolith tree.
- Context: Async ingestion was proven on the microservices
  (`finrecon.ingest.v1`, eventId dedupe, 3x retry + DLT) and measured
  once (`data/evaluation/p13_kafka.json`, pre-monolith, 2026-09-18).
- Decision: The monolith runs broker-less by default for the 8GB
  footprint; messaging code was removed in consolidation and
  `docker-compose.yml` runs PostgreSQL only. Reintroduce Kafka/Redis
  only where brokers exist, behind the same conditional flags.
- Consequences: No broker cost or RAM by default; sync ingest is the
  supported path. Kafka rows in `docs/METRICS.md` are historical until
  re-measured on this tree.
- Tests/artifacts: `data/evaluation/p13_kafka.json` (historical),
  `docs/EVENTS.md` (contract kept).
