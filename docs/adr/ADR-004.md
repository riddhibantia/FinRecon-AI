# ADR-004 — PostgreSQL + pgvector for RAG

- Status: Accepted (P7).
- Context: Policy evidence must stay close to the system of record
  with document/version metadata intact.
- Decision: pgvector on the same PostgreSQL instance; chunks retain
  document ID, title, version, effective dates, page/section.
  Signed-hash embeddings (`finrecon-signed-hash-1536-v1`); no external
  embedding service required.
- Consequences: One database to operate; retrieval evaluated on a
  fixed 12-question synthetic set (Recall@3 1.0, MRR@3 1.0, both
  memory and live-Postgres backends).
- Tests/artifacts: `ai-service/tests/test_rag.py`,
  `evaluation/p7_metrics.json`, `evaluation/p7_postgres_metrics.json`.
