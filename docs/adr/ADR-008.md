# ADR-008 — Rule/model/prompt versioning

- Status: Accepted (P3+, extended P6–P8, holds in P13).
- Context: Every result must be reproducible from stored inputs plus
  recorded versions.
- Decision: `rule_version` (`1.0.0`) on every reconciliation run;
  `modelVersion` (`p6-d92893deeb5ca075`) on every classification;
  investigation records carry model/prompt versions; dataset lineage
  (seed, hashes, engine source) lives in `p6_metrics.json`.
- Consequences: Metrics are traceable to exact code + data; reruns
  never silently change meaning.
- Tests/artifacts: `ReconciliationServiceTest`,
  `evaluation/p6_metrics.json` (`dataset_lineage`),
  `evaluation/p13_agent_metrics.json` (`evaluated_at`).
