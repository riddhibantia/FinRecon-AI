# ADR-005 — LangGraph workflow choice

- Status: Accepted (P8).
- Context: Investigations must be explicit, testable step sequences,
  not free-form generation.
- Decision: A fixed grounded workflow (classify -> load evidence ->
  query records -> similar cases -> retrieve policy -> root-cause ->
  draft -> verify citations -> summary -> human review) with tool
  calls for every financial fact. Conflicting/insufficient evidence
  yields `HUMAN_REVIEW`/`MANUAL_REVIEW`, never a guess.
- Consequences: Measured 1.0 task success on the fixed 6-case offline
  set; citation correctness 1.0; injection text cannot alter outcomes.
- Tests/artifacts: `ai-service/tests/test_agent.py`,
  `tests/test_agent_evaluation.py`, `evaluation/p13_agent_metrics.json`,
  `tests/test_prompt_injection.py`.
