# ADR-001 — PostgreSQL as source of truth

- Status: Accepted (P1, still holds after monolith consolidation).
- Context: Three source systems disagree; reconciliation needs one
  reproducible store for payments, ledger entries, settlements, runs,
  results, exceptions, evidence, feedback, and audit.
- Decision: PostgreSQL 16 is the system of record. `db/migrations`
  owns the schema via Flyway; runtime uses `ddl-auto=validate`.
- Consequences: Single backup/restore story; H2 exists for tests only
  and never validates PG DDL. pgvector rides on the same instance.
- Tests/artifacts: `python -m pytest db/tests -q`, `db/migrations/`.
