# ADR-006 — Fine-tune classifier vs main LLM

- Status: Deferred on measured evidence (P9).
- Context: 3,000 synthetic rows / 200 payment families exist, but all
  labels come from the deterministic engine's own 16 mutation
  templates; baseline heldout macro F1 is already 1.0 on all nine
  classes with no measured failure mode.
- Decision: No PyTorch/PEFT dependency, GPU cost, or experiment
  complexity. Revisit only when independent analyst-labeled cases
  (via the FR-11 feedback path) exist and the baseline shows measured
  room for improvement on them.
- Consequences: `LogisticRegression` stays the selected model (tie
  with XGBoost broken toward transparency).
- Tests/artifacts: `docs/ML.md` (P9 decision), `evaluation/p6_metrics.json`.
