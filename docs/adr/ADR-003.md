# ADR-003 — Deterministic reconciliation before ML/LLM

- Status: Accepted (P3, unchanged).
- Context: Financial truth must not depend on probabilistic models.
- Decision: `ReconciliationEngine` applies fixed first-failure checks
  (duplicate, missing, amount, unknown, fee, net/partial, FX, status,
  late) under `RULE_VERSION 1.0.0`. ML classifies already-detected
  exceptions; the LLM never decides numeric truth.
- Consequences: Same input always yields the same outcome; reruns
  write new run rows with identical result content. Status check is
  normalized string equality (no lifecycle mapping — documented
  simplification).
- Tests/artifacts: `ReconciliationEngineTest` (16 tests),
  `ReconciliationServiceTest`, `data/demo/scenarios.json`.
